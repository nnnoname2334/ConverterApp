## Описание проекта

Графическое WPF-приложение «Конвертер величин», которое позволяет конвертировать:
- Метры → Километры
- Километры → Метры
- Градусы Цельсия → Градусы Фаренгейта
- Градусы Фаренгейта → Градусы Цельсия
